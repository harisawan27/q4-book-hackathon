# Target Audience

This module is designed for **Senior Undergraduate** and **Graduate** students in Engineering fields.

## Academic Background
Students should have completed coursework in:
-   **Linear Algebra**: Matrices, Vectors, Transformations.
-   **Programming**: Python (intermediate) and C++ (basic).
-   **Control Theory**: PID controllers (beneficial but not strictly required).

## Hardware Requirements
-   Access to a Windows or Linux PC with an NVIDIA RTX GPU (for Isaac Sim).
-   Alternatively, access to a university lab workstation.

## Career Pathways
Completing this module prepares students for roles such as:
-   **Robotics Software Engineer**: Building the stack for autonomy.
-   **Simulation Engineer**: Creating digital twins for testing.
-   **AI/ML Engineer (Robotics)**: Deploying models to the edge.
