# Preface

## Welcome

Welcome to the **Physical AI & Humanoid Robotics Capstone Module**. This comprehensive guide is designed to take engineering students from the fundamentals of Robot Operating System (ROS 2) to the deployment of a fully autonomous humanoid robot in a high-fidelity simulation.

## Purpose

The field of robotics is undergoing a paradigm shift towards **Physical AI**—systems that can perceive, reason, and act in the physical world using foundation models. This course bridges the gap between classical control theory and modern AI-driven robotics.

## Course Structure

This book is organized into four core modules and a capstone project:

1.  **Module 1: The Robotic Nervous System**: Mastering ROS 2, the industry-standard middleware.
2.  **Module 2: The Digital Twin**: Building physics-accurate simulations in Gazebo and Unity.
3.  **Module 3: The AI-Robot Brain**: Leveraging NVIDIA Isaac Sim for perception and training.
4.  **Module 4: Vision-Language-Action**: Integrating Large Language Models (LLMs) for cognitive planning.

## Learning Outcomes

Upon completion of this module, students will be able to:

1.  **Physical AI Mastery**: Architect systems that bridge perception, reasoning, and actuation in real-time.
2.  **ROS 2 Proficiency**: Develop custom ROS 2 nodes, topics, and action servers using C++ and Python.
3.  **Simulation Fluency**: Create "Digital Twins" with accurate URDF physics and sensor plugins in NVIDIA Isaac Sim.
4.  **Cognitive Planning**: Implement VLA (Vision-Language-Action) pipelines to translate natural language instructions into robot trajectories.
5.  **Deployment**: Successfully deploy a containerized application to an edge device (Jetson Orin) and demonstrate Sim-to-Real transfer.

## Intended Audience

This material is intended for senior undergraduate or graduate students in:
-   Robotics Engineering
-   Computer Science (AI/ML specialization)
-   Mechatronics

Prerequisites include Python programming, Linux command line basics, and linear algebra.
